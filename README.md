# CS2800

University Software Engineering coursework project developed as part of the CS2800 module.

## Overview

This project was developed for the CS2800 Software Engineering coursework. It demonstrates the application of software engineering principles and practices throughout the development process.

## Features

* Core functionality developed as part of the coursework
* Structured and maintainable codebase
* Object-oriented software design
* Testing and validation
* Version control using Git

## Technologies

* Java
* JavaFX
* Javadoc
* TDD
* UML
* Git
* JUnit
* Maven

## Getting Started

### Prerequisites

Make sure you have the following installed:

* Java JDK
* Maven
* Git

### Running the Project

Clone the repository:

```bash
git clone https://github.com/AbdullahAamir-Codes/Calculator_CS2800.git
cd CalculatorCW
```

Build the project using Maven:

```bash
mvn clean install
```

Run the application using the appropriate entry point for the project.

## Testing

Tests can be run using:

```bash
mvn test
```
